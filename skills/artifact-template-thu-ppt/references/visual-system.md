# 视觉规范

画布 1280 × 720，输出对应 960 × 540 pt。正文顶栏使用 `#660874`，左上白色主标题，下方一行浅紫副标题。封面紫色色块占上方 328 像素，下半区放中文题目和作者信息。右上给机构标志留足空间。[设计参数](../assets/design-tokens.json)

| 对象 | 起始参数 |
| --- | --- |
| 正文标题及副标题 | 标题 30 pt，副标题约 14 pt |
| 正文与图示 | 说明约 18–21 pt，图内短标签约 14 pt 起 |
| 来源与页码 | 页脚细线在 y=672，来源约 9–11 pt，页码右对齐 |
| 颜色 | 正文近黑，辅助文字深灰，表头灰紫，重点行淡紫 |
| 文字 | 首选 Noto Sans SC，可选思源黑体或微软雅黑。交付前检查目标设备的中文回退 |
| 表格 | 原生单元格、浅色行、细分隔线。数字精度及对齐方式保持一致 |

普通页内容约在 x=54 至 1216、y=148 至 650 内。双栏留出栏距；三栏使用同尺度。段落过多时先删减重复解释，再调整版面。将图注放在对应对象附近。原文图的颜色如果表达数据含义，应保留原来的映射。

复制页时检查形状样式、表格填色和主题强调色。封面、正文及导出稿的同类对象要对齐。新加的公式检查减号、上标、下标和单位。
