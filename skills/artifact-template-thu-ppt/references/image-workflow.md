# 科研图与公式

| 内容 | 制作方式 | 核验重点 |
| --- | --- | --- |
| 方法与架构 | 优先原生形状、连接线、文字或可维护的 SVG | 实体、训练和推理的可见信息、箭头方向及图例 |
| 关系矩阵 | 用原生网格，说明行和列的含义 | 掩码的读取方向、允许访问的区域 |
| 原文实验图 | 从可用的原始来源提取，优先矢量 | 坐标、刻度、单位、条件、误差区间和图号 |
| 有数据的曲线和表 | 由原始数据绘制，保留数据和绘图源 | 对齐样本、统计方法和有效数字 |
| 数学表达 | 优先原生 Office 公式，或保留 LaTeX 的矢量公式 | 变量、前提、上下标和公式的实际可编辑程度 |
| 概念插画 | 需要时使用生成式图像并在上下文说明其示意用途 | 对象数、关系和标签是否准确 |

绘图前先写下输入、输出、可训练参数与更新目标。原生连接线应随节点移动，箭头朝向接收信息的节点。监督关系可采用虚线，并在图中解释。同一颜色情形对应同一含义。生成式图片适合概念素材；精确的实验曲线、公式和架构拓扑应直接来自可核验材料。

示例演示的数据可以用[计算脚本](../scripts/example_windows.py)复算。公式的可复制源见[LaTeX 文件](../assets/formulas.tex)。
