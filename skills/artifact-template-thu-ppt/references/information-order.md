# 信息排列

拟定页面前先写下这一页要解决的问题。论文报告的一条常用主线是研究动机、问题、方法、比较协议、结果和局限。方法占比随受众和任务调整。改版已有报告时先保留已有结构。

## 方法

- 整体图交代输入、输出、训练信号和推理路径。局部页解释一条关系、一个目标或一个模块。
- 左右对照使用相同尺度及指标。训练时使用而推理时不可见的信息用文字和图例标明。
- 将公式与变量解释邻近排列，尽早给出读者需要的前提；较长推导可放备注或附页。
- 演进图的连接由资料中的技术关系决定。独立路线可并列呈现，年代接近本身不足以连接两项工作。

## 结果

先交代样本、划分、基线、指标方向和聚合方式，再呈现结果。让观众在图表附近看到改变解释的条件。比较表中突出与本页问题有关的一行或一列。比较成本时写明数据量、设备和计时范围。

每张证据图旁放一条能由图支持的解读。段落过长时，把背景和符号详解移到本页备注。中文讲稿应解释观众如何读图、结论依赖的条件，以及下一页要解决的问题。
